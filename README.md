# IPL-Data-Analysis
Exploratory Data Analysis on IPL dataset using Python, Pandas and Matplotlib. Insights on team performance, top batsmen, bowlers, toss impact and venue statistics

## Insights Covered
- Most winning teams in IPL history
- Top run scorers across all seasons
- Top wicket takers across all seasons
- Impact of toss on match result
- Venues with most matches played

## Tools Used
Python, Pandas, Matplotlib

## Dataset
IPL complete dataset with matches.csv and deliveries.csv
